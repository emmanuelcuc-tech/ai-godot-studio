# Demolition (Codea) v1.2

Wrecking-ball + **TNT** demolition with standard energy equivalence and material fracture.

## TNT (standard)
- **1 g TNT = 4,184 J** (4.184 kJ/g)
- **1 ton TNT = 4.184 × 10⁹ J** (4.184 GJ)
- Blast overpressure via **Kinney–Graham** `Z = R / W^(1/3)`
- Also uses surface intensity `I = P / (4π r²)`

Buffers: `TNT` → `Materials` → `Levels` → `Main`

## Materials
Glass shatters · Wood splits · Concrete spalls · Steel bends · Rebar holds

## Install
Unzip `Demolition-COPY-PASTE.zip` → copy `Demolition.codea` into Codea.
