# Images (drop-in)

Place new textures here. Until then, keys use procedural cream/chrome.

| File | Use |
|------|-----|
| `key.png` | Keycap (rest) |
| `key_pressed.png` | Keycap (pressed) |
| `striker.png` | Typebar / striker cinema (optional) |
| `paper.png` | Optional global paper override |
| `paper/recycled.jpg` | Paper type: Recycled fiber |
| `paper/kraft.jpg` | Paper type: Kraft gray |
| `paper/beige.jpg` | Paper type: Plain beige |
| `paper/underwood_desk.jpg` | Paper type: Underwood desk photo |

Paper JPGs were imported as **paper types** for Settings (not claimed as TypingSimulator assets).  
TypingSimulator-main is an MIT auto-typer (see `assets/TYPING_SIMULATOR_LICENSE.txt`) with no bundled textures.

Alternate key paths: `assets/keys/key.png`, `assets/keys/key_pressed.png`, `assets/keys/striker.png`.
