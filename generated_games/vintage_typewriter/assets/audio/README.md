## Keymulate packs
Copied from `F:\keymulate-main.zip` as `km_<name>/` (same switch-style sets).

Each pack:
- `press/` — BACKSPACE, ENTER, SPACE, GENERIC_R0..R4
- `release/` — BACKSPACE, ENTER, SPACE, GENERIC

**Default:** `buckling`

## Mechanical extras
- `bell.ogg` — margin bell
- `return.ogg` — carriage return
- `erase.ogg` — backspace

Choose pack in **Settings → Sound source**.
