# Paper & sound (reset)

## Controls (real typewriter feel)

- **Return / new line** → platen advances **automatically**
- **FEED ↑ / ↓** and knobs → manual feed buttons
- **Grab & drag on the sheet** → manual pull/adjust only (where you grab matters)
- Typing does **not** slide the whole page around

## Paper

- Fixed size (no squash/stretch deform)
- Position only from platen offset + light breath tilt + grab tug
- Texture aspect kept centered in the paper view

## Sound

Clean dry SFX only: key click, return clunk, platen tick, margin bell.  
No ambient bed, no flutter loop, no mic monitor.

Scripts: `typewriter_sfx.gd`, `paper_aero.gd`, `paper_grab.gd`
