# Vintage Typewriter (iPad)

Full-screen mechanical typewriter with separate **Typewriter** and **Settings** views.

## Typewriter (main)
- All keys touch-interactive (QWERTY + shift glyphs)
- Paper feed via **platen knobs** or drag on paper
- Paper release, margin release, tab set/clear, shift lock
- Carriage return + line space + margin bell
- Spring haptic (peak → soft) + key bounce + typebar flash + click/bell

## Settings
- Paper types: white, tinted yellow, vintage, green, blue, red, yellow, black
- Custom paper color picker
- Font: regular / bold / italic, size, single/double spaced
- Font color presets + full color picker
- HQ: **4K paper** + **2K key sprites** (or 2K/1K)
